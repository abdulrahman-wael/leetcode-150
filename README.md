# My Leetcode 150

This is my solution to Leetcode 150 top-interview questions.

my methodology

1. Each problem is solved in one file in an executable way
2. Any links to tutorials or good approaches will be mentioned in the comments of the solution
3. After solving the problem I'll categorize it based on the algorithm it's solved with ... and if it can be solved using multiple algorithms I'll mention this in a comment using the keyword: RELATED ALGO .. so you can search the keyword for these types of problems.
4. After finishing a handful of problems in each category I'll create a create a file with all the notes related to this type of problem (Insha'allah).
